# iOS 预览页：长按屏幕退出预览

## 背景

现在退出预览要点左上角的关闭按钮，单手持机时够不到。
希望**长按画面**即可退出，手指在哪都行。

只做 **iOS**，web 端不需要改。

## 范围

- `iOS/ReSourcer/Views/Gallery/FilePreviewView.swift` —— 媒体区域接入长按
- 手势逻辑放独立文件（同 RS-003 的硬约束）
- **明确不做的**：不碰 web / server；不删除现有的关闭按钮（长按是补充，不是替代）

## ⛔ 硬约束

同 RS-003：`FilePreviewView.swift` 已 2262 行，**只许变短**，guard 的 linecount 棘轮会拦。

## 实现方向

- 长按目标是**媒体显示区域**（图片 / 视频画面），不是工具栏。
- 现有 `onLongPressGesture` 已被占用在两个工具栏按钮上：
  - 文件名 Capsule → 快捷操作面板
  - 播放模式按钮 → 播放列表 popover

  **这两个必须保持原样**，不能被新的全屏长按吞掉。
- 长按时长要和「长按后拖动」区分开：用户正在放大平移或做 RS-003 的 seek 拖动时，不该误触发退出。
  建议设一个最短时长 + 最大位移容差，手指移动超过容差就取消退出。
- 退出前给一点反馈（触觉或短动画），避免用户以为是误触崩了。
